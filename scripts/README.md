# Scripts

This directory contains standalone utility scripts for data migration, refactoring, and database seeding.

- `refactor.cjs`, `refactor2.cjs`, `refactor3.cjs`: Scripts used for legacy code refactoring.
- `restructure.js`: Script used for restructuring project data.
- `split_data.js`: Script used to split data into separate chunks.
- `seed_admin.mjs`: Script to seed admin credentials into the database. Note: Excluded from version control to prevent credential leakage.
